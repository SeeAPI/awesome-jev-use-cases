查看已有的[作者评测与行为研究](../docs/casebook.zh-CN.md#评测与行为研究)。

**本次结构调整没有发布新的独立模型评测结果。** 离线配方样例测试的是解析与路由逻辑，不是 Jev 准确率。已有研究结果继续归属于原作者。

可复现的评测报告需要：

- 有版本记录且可公开的数据集，包含标注规则和模糊样本。
- 明确的策略、问题、请求与返回模型、供应商及日期。
- 原始响应、失败请求、计时定义与用量；费用结论需要账单证据。
- 各类别错误、覆盖率、弃权及测试条件，而不只展示成功样例。
- 可执行的评估流程，区分离线验证与付费 API 调用。

详见[证据要求](../docs/evidence.zh-CN.md)。添加数据集或评估协议本身，不代表已经获得执行或发布授权。
